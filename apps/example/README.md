# IslandKit example app

An Expo Router showcase for [`expo-island-kit`](../../packages/expo-island-kit/README.md), with one
screen per preset: Now Playing, Generic Progress, Delivery and Timer. Each screen starts, updates and
ends a single Live Activity and prints the returned activity id so failures are visible.

This app consumes IslandKit exactly like any other consumer: the widget extension under
`targets/island-kit-widget/` is generated by the package's config plugin at prebuild time and is not
tracked in git.

## Requirements

- iOS 16.2 or newer. A Dynamic Island needs an iPhone 14 Pro or newer; on older devices the activity
  still renders as a Lock Screen banner.
- Xcode 26.4+ (Swift 6.3).
- Node 22 (see `.nvmrc`) and pnpm 10.17.
- iOS only — there is no Android configuration here.

## Run it

From the repository root:

```bash
pnpm install
```

Then from `apps/example`:

```bash
npx expo prebuild -p ios --clean
npx expo run:ios
```

To run on a physical device (the only way to see a real Dynamic Island):

```bash
npx expo run:ios --device <udid>
```

`--clean` on prebuild is required. Running a plain `expo prebuild` over an existing generated widget
target fails with `withIosXcodeProjectBeta2BaseMod: Cannot read properties of undefined`. Re-run the
`--clean` prebuild any time you change something under `packages/expo-island-kit/plugin/` or `ios/`,
otherwise you are testing stale native code.

## Signing on a free Apple ID

This project is set up for a free Apple ID / Personal Team. After the first install on a device:

1. Open **Settings ▸ General ▸ VPN & Device Management** on the device.
2. Trust the developer certificate for your Apple ID.
3. Launch the app again.

Personal Team certificates expire after **7 days** — after that the app stops launching and you need
to rebuild and reinstall it.

## Layout

```
app/
├── _layout.tsx           Stack navigator with a dark header
├── index.tsx             Preset list + areLiveActivitiesEnabled() readout
├── now-playing.tsx
├── generic-progress.tsx
├── delivery.tsx
└── timer.tsx             Start / Pause / Resume / End
components/
└── DemoScreen.tsx        Shared shell: title, description, status line, buttons
```

Deep links use the `islandkitexample://` scheme declared in `app.json`; every preset passes one to
`start()`.
